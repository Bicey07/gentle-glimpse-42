# Gentle Echoes

请帮我做一个网页 App 原型。

产品定位：

一个没有点赞、没有比较的生活记录空间。

用户可以留下生活痕迹，也可以被朋友温柔地看见。

核心页面：

1. Home：朋友生活流

2. Add：极轻发布入口

3. Me：我的个人空间

4. Friend Profile：朋友空间

内容类型：

- 一句话

- 一张图

- 一本书

- 一部电影

- 本周状态

产品规则：

- 没有点赞

- 没有粉丝数

- 没有排行榜

- 没有热门推荐

- 只允许评论或一句话回应

视觉风格：

安静、温柔、低压力。

不要像 Instagram，不要像小红书。

颜色偏米白、灰蓝、淡绿。

界面要像一个可以安静生活的空间。

技术要求：

先只做前端原型。

使用假数据。

不用登录。

不用后端。

用 React + Tailwind。
