## 产品概览

一个安静、温柔的生活记录网页原型。没有点赞、没有粉丝、没有排行榜，只能留下痕迹和被温柔看见。纯前端，假数据，无登录无后端。

## 视觉风格

- **基调**：米白底 (#F7F4EE)、灰蓝点缀 (#8AA0B4)、淡绿强调 (#B8C9B0)，文字用暖灰 (#3D3A35)
- **字体**：中文用 Noto Serif SC（衬线，安静感），英文/数字用 Inter
- **质感**：大量留白、柔和圆角 (rounded-2xl)、无阴影或极淡阴影、细 1px 分隔线
- **动效**：仅淡入和柔和的 hover 透明度变化，无弹跳、无炫技

刻意避免：鲜艳色块、徽章数字、红点提醒、卡片堆叠密集、emoji 表情雨。

## 页面结构

### 1. Home —— 朋友生活流
- 顶部一行问候语（如「今天也安静地过」），右上角小小的「+」入口
- 时间倒序的内容流，每条记录是一张极简卡片：
  - 头像（小、圆形）+ 朋友名字 + 相对时间（「昨天傍晚」）
  - 内容主体（按类型不同样式渲染，见下）
  - 底部仅一个动作：「回应」（点开是一行输入框，不显示数量）
- 不显示任何"热门""推荐"，纯时间线

### 2. Add —— 极轻发布入口
- 全屏单列，顶部一个问句：「今天想留下什么？」
- 五个内容类型作为横向小标签：一句话 / 一张图 / 一本书 / 一部电影 / 本周状态
- 选中后下方出现对应的极简表单（最多 2-3 个字段）
- 底部一个浅色「留下」按钮，无草稿、无定时、无标签选择

### 3. Me —— 我的个人空间
- 顶部：头像 + 名字 + 一行自我描述（可编辑感的占位）
- 下方分两栏小目录：「最近的痕迹」「本周状态」
- 时间线展示自己的内容，与 Home 卡片同样式但更窄
- 无任何统计数字（不显示发布数、朋友数）

### 4. Friend Profile —— 朋友空间
- 与 Me 同结构，但右上角是「轻轻打个招呼」入口（一句话私信感）
- 展示该朋友的痕迹，按时间线
- 无关注按钮，只有「保持联系」的浅色文字开关

## 内容类型卡片样式

- **一句话**：大字号衬线引文样式，无引号装饰
- **一张图**：图片占主体，下方一行可选说明，无滤镜无标签
- **一本书**：左侧小封面缩略 + 右侧书名/作者 + 一行感受
- **一部电影**：同书，但封面比例不同
- **本周状态**：一个柔和色块 + 一行心情词（如「平静」「想念」「在恢复」），仅本人和朋友可见

## 假数据

- 5-6 个虚构朋友（中文名字，如「林一」「小满」「阿野」）
- 12-15 条混合类型的内容
- 图片用 Unsplash 静物/风景占位，书影用经典作品

## 技术栈

- Vite + React + TypeScript（项目已有）
- Tailwind CSS + 自定义 design tokens 写入 index.css
- React Router 实现 4 个页面路由
- 数据放在 `src/data/mockData.ts`
- 组件结构：
  ```text
  src/
    pages/        Home, Add, Me, FriendProfile
    components/   PostCard, TypePill, QuietButton, Avatar, BottomNav
    data/         mockData.ts
    lib/          types.ts
  ```
- 底部一个极简 3 项导航条：Home / Add / Me（朋友空间从 Home 点头像进入）
